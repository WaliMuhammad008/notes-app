# Notes App

A simple and responsive Notes Application that allows users to create, manage, and organize their notes easily.

## Features

- Create new notes
- Edit notes
- Delete notes
- Save and manage notes
- Clean and user-friendly interface
- Responsive design

## Technologies Used

- HTML
- CSS
- JavaScript

## Description

This project is a Notes Application developed to help users manage their daily notes efficiently. Users can add, update, and delete notes through a simple and interactive interface.
